# Synthetic-Data-for-Object-Detection
To enhance the performance of remote sensing object detection, we construct synthetic datasets: Syn-DIOR and Syn-DIOR-R. Syn-DIOR and Syn-DIOR-R share the same set of 50, 000 images covering 20 object categories, but differ in their annotation formats.
